Employee Management System
An Employee Management System that allows administrators to manage employee details, including their departments, personal information, job roles, and salary. The system is built using React for the frontend and Spring Boot for the backend.

Features
Add Employees: Add new employee details including name, department, job title, email, phone number, and salary.

View Employees: List of employees with their basic information displayed in a tabular format.

Update Employee Information: Ability to edit employee details such as name, department, salary, etc.

Delete Employee: Remove an employee from the system.

Department Management: Manage employee departments, including adding, updating, and deleting department data.

Tech Stack
Frontend
React: A JavaScript library for building user interfaces.

Axios: Promise-based HTTP client for making API requests.

React Router: For navigation between pages.

Backend
Spring Boot: A Java-based framework used to create stand-alone, production-grade Spring-based applications.

MySQL: Database used to store employee and department data.

Prerequisites
Before you begin, ensure you have met the following requirements:

Node.js and npm are installed on your system for running the React frontend.

Java JDK (Java Development Kit) is installed for running the Spring Boot backend.

MySQL is installed and running on your local machine to store data.
